# Security policy

## Reporting a vulnerability

Use **GitHub private vulnerability reporting** on the affected repository
(Security → Report a vulnerability). Do not open a public issue for a
vulnerability, a leaked credential, or a personal-data exposure.

Include the repository, the affected path or URL, reproduction steps, and the
impact you can prove. We aim to acknowledge within 7 days and to ship or
explicitly decline a fix within 90 days.

## Scope

Public repositories in this account, their GitHub Actions workflows, and any
site deployed from them. Out of scope: third-party services, scanner output
without a reproduction, and social engineering.

## Not in scope but still welcome

Data corrections go through the normal issue form, not this channel.
