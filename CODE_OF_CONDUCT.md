# Code of conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Enforcement

Report unacceptable behaviour to the maintainer listed in the repository
profile. Reports are handled privately. Maintainers may remove comments,
close threads, or block accounts for behaviour that violates the covenant.

## Scope

Issues, pull requests, discussions, reviews, and any space where the project is
represented.
